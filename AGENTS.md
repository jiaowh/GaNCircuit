# Project continuity

Read `README.md` for current implementation status and links to executed results, then `plans/autonomous-circuit-toolset-plan.md` for the active direction. Inspect current files before relying on historical chat summaries; implementation may have progressed in another session.

The project prioritizes reusable tools for autonomous semiconductor-device and circuit co-design. Custom physical device design is in scope from the start. Earlier fidelity/ranking protocols are historical research profiles, not the active implementation priority.

For diode and planar-MOSFET verification or benchmarking, read `docs/device-benchmark-sources.md`. It records the public sources selected for assessment, their evidence limits, and the intended validation sequence. Keep simulated reference data, vendor-described measurements, model-fit validation, and physical-device validation distinct.
